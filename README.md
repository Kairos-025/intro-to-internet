# Intro to the Internet

Hand-made websites written in plain HTML, CSS and JavaScript, with Bootstrap used for one navbar.

| Folder | What it is |
|---|---|
| `mybio/` | **My Bio**: a four-page personal site (about, education, work, hobbies) with a feedback form, a table and image maps |
| `myproject/` | **My Project**: a ten-page site about hobbies with a dropdown menu, image maps, a table, a feedback form and a citations page |
| `New/` | **Kemz**: a responsive Bootstrap navbar that collapses into a menu on small screens |

Open `index.html` to browse all three.

## Features

- Valid, semantic HTML5 (`header`, `nav`, `main`, `section`, `figure`, `footer`)
- Responsive layouts that work on phones, tablets and desktops
- Accessible navigation: skip link, `aria-current` on the current page, a keyboard-friendly dropdown that closes with Escape, visible focus outlines
- Clickable image maps linking parts of photos to related sites
- Feedback forms that open the visitor's email app (no server needed)
- Optimized images sized for the web

## Run it

No build step. Open `index.html` in a browser, or publish the repository with GitHub Pages (Settings → Pages → deploy from the `main` branch).

Image credits are listed on the **Citations** page of My Project and in the **Works Cited** section of My Bio.
